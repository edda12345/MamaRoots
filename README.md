# MamaRoots — Culturally Nourished Motherhood

A mobile-first pregnancy companion designed for the **Women's Health & Wellness** track, bridging everyday prenatal nutrition and ingredient/food safety with cultural traditions such as *pantang larang* and regional lifestyles[cite: 4, 5, 9].

## Key Features
- **Tracker (Main View):**
  - Displays pregnancy week, days along, trimester badge, baby size comparison, milestone notes, and an interactive week stepper[cite: 5, 7].
  - Includes a daily mood check-in (**Glowy**, **Cozy**, **Tired**, **Queasy**) to tailor daily food and self-care suggestions[cite: 5, 7, 8].
  - Supports meal logging via text, one-tap quick meal chips, or photo preview to estimate calories, protein, folate, and iron while flagging user-configured profile allergies[cite: 5, 8].
  - Provides **What to Focus On Eating Today** and **What to Do Today** guidance cards[cite: 5, 8].
  - Features an on-demand **Cultural Guide & Pantang Larang** modal with regional context and safety reminders (such as *pantang larang*, cooling/warming balance, skincare cautions, and raw/risky foods like sushi)[cite: 5, 9].
- **Discover:** Community feed for sharing pregnancy moments, cravings, and cultural tips across regions and lifestyles (`All`, `Asian`, `Western`, `Blended`)[cite: 5, 10].
- **Profile:** Lets users customize name/nickname, pregnancy week, location, height, weight, lifestyle mode (**Asian Lifestyle**, **Western Lifestyle**, **Blended Roots**), and allergies, alongside a **Bump & Memory Album** roadmap teaser[cite: 5, 11].

## Tech Stack & Persistence
- **Frontend:** HTML5 (`index.html`), CSS3 (`styles.css`), Vanilla JavaScript (`app.js`), and custom brand/visual assets (`logo.jpg` and inline SVG visuals)[cite: 1, 5, 6].
- **Data Storage & Logic:** Browser `localStorage` for persisting profile settings, moods, logged meals, and posts across refreshes, paired with client-side keyword-based nutrient estimation and allergy matching in the prototype[cite: 5].
